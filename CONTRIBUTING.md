# Contributing

Thanks for helping! Bug reports, ideas and pull requests are all welcome, including new pieces other mods could use. For questions and discussion, join the [Discord server](https://discord.gg/YKdTjge7J2).

## Issues

- Use the issue templates. For bugs, include the API version and the mod you saw it in, the game version, what you expected and what happened, and `BepInEx/LogOutput.log` from the game folder.
- Remove anything private from logs and screenshots before posting (names, IP addresses, Steam IDs).

## Pull requests

- Every pull request is reviewed by a maintainer; nothing is merged automatically.
- Each contributor can have **at most 2 open pull requests** at a time (a workflow closes extra ones with a note; reopen it once one of the others is merged or closed).
- Keep a pull request focused on one change and describe how you tested it (offline tests, and a live game check for anything touching the game).
- Match the surrounding code style; the `AGENTS.md` files describe the project's rules and invariants.
- Never add game files, game assemblies or decompiled game code. The API compiles against your local game install (see the README).
- By contributing you agree that your contribution is licensed under the repository's MIT license.
